#📚 Sistema de Biblioteca

Um sistema web desenvolvido para facilitar o gerenciamento de uma biblioteca. A aplicação permite cadastrar, consultar, editar e remover livros, tornando a administração do acervo mais simples e organizada.

✨ Funcionalidades

- 📖 Cadastro de livros
- 🔍 Pesquisa de livros por título ou autor
- ✏️ Edição das informações dos livros
- 🗑️ Remoção de livros
- 📚 Listagem completa do acervo
- 📱 Interface responsiva

🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

🚀 Como executar o projeto

1. Clone este repositório:
   
   git clone (https://github.com/victoremmanuel1706-lab/Projeto-Biblioteca-Victor)

2. Acesse a pasta do projeto:
   
   cd Projeto Biblioteca
   
4. Abra o arquivo "index.html" no navegador.

💡 Objetivos do Projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento web, como organização de código, manipulação do DOM, responsividade, uso do Git/GitHub e criação de uma interface intuitiva para gerenciamento de dados.
